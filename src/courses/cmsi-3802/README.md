## cloudscribe

`cloudscribe/` is the CMSI 3802 state of the project, at commit `25b48f1`. It is an
archive, not the current codebase. The project continued after the course and is
maintained at [`cloudscribe`](https://github.com/patrickking67/cloudscribe), which has
since diverged by 46 commits. Do not push this directory to that remote.

Full course-era history, all 77 commits across both lineages, is preserved in
`CMSI-3802_cloudscribe.bundle`. See [`docs/archive.md`](../docs/archive.md).
