# Pathfinder Setup Guide

## How to Start the Backend

```bash
cd backend
npm install  # Install dependencies
node index.js    # Start the backend server
```

---

## How to Stop the Backend

Press `CTRL + C` in the terminal where the backend is running.

---

## How to Start the Frontend

```bash
cd frontend
npm install 
npm run dev  
```

---

## How to Stop the Frontend

Press `Crtl C` in the terminal where the frontend is running.

---

## Technologies Used

### Frontend
- **React.js** (Vite)
- **React Router** (Navigation)
- **Firebase** (Auth + Firestore)
- **CSS**

### Backend
- **Node.js + Express + Vite** (Server)
- **Firebase Admin SDK** (User data management)
- **ChatGPT** (AI Chatbot)
