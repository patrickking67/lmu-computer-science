FUNCTIONAL REQUIREMENTS:
   I like the way you have numbered the requirements ~ a bit unconventional,
   but still gets the point across and is trace-able which is what is needed
   for proving requirements are met.

   I think, however, that for an application of this size and complexity,
   you need more requirements overall, especially functional ones.  You need
   quite a bit more detail in all the "FR" requirements; for example in FR5
   you specify an AI chatbot assistant but that top-level requirement is the
   only specifier for that component.  There are a number of questions about
   that piece that need requirements, such as:

      Where will the chatbot appear?
      How will the user interact with it?
      What type of algorithm will be used?
      What is the definition of "career-related"?
      Where will the responses come from ~ a database?
      etc.

   There needs to be significant thought put into the requirements so that
   these and other questions and the responses get written down.
