# CMSI 3300

Artificial Intelligence. Fall 2024.

No working tree survives. The five homework repositories were GitHub Classroom repos
under the `cmsi3300-02-fall24` organization; their histories are preserved as bundles and
their contents are not vendored here. See [`docs/archive.md`](../docs/archive.md).

What is here is the course material, vendored 2026-08-22 from iCloud.

## Grades

source carried the same percentages.

## HW3 Answers

The four solution sets in `HW3 Answers (Pacman AI)/` are distinct implementations, not
revisions of one file. They carry the UC Berkeley CS188 licence, which forbids publishing
solutions, so they are held out of version control until the author decides. See
[`docs/publication.md`](../docs/publication.md).
