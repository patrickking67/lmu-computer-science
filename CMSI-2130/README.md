## Why these are CMSI 2130, not CMSI 2120

Dr. Forney's published CMSI 2130 homework set maps onto the preserved projects one for
one. CMSI 2120 is Data Structures and shares none of them.

| Assigned homework | Preserved project |
|---|---|
| Homework 1, A\*-y Night | `A* Pathfinder` |
| Homework 2, Tic'd Off | `Tic Tac Toe Game` |
| Homework 3, Distle'd Knowledge | `Distle Game` |
| Homework 4, Huff and Puff | `Huffman Coding Compression` |
| Homework 5, Arc Nemesis | `Constraint Satisfaction Problem` |

The syllabus consulted is the Spring 2026 offering while these commits date to
2023-07-24, so the match shows the assignment set is stable across offerings. It fixes
the course, not the term.
