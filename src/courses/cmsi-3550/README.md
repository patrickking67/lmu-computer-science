# CMSI 3550: Networks and Internets - Coursework Repository

Welcome to the coursework repository for **CMSI 3550: Networks and Internets**, taken in the Spring of 2024 at Loyola Marymount University. This repository contains projects, assignments, and various learning materials curated by Patrick King throughout the duration of the course.

## Course Overview

This course dives deep into the fundamentals and advanced topics of computer networking and internet technologies, covering a wide array of subjects from the OSI model and TCP/IP protocols to modern networking standards and practices.
