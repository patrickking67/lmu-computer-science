# CMSI 3920

Computing Contexts and Ethics. Summer 2024 Session I.

Satisfies the Ethics and Justice core requirement and counts as an additional
upper-division computer science course, so it carries both Core and Major credit.

One course reading survives: Nancy Fraser's 2010 article on social exclusion and the
global poor. It is a third-party scholarly article rather than instructor-authored
material, so it sits in the working tree uncommitted until the author decides whether
redistributing it is acceptable. See [`docs/publication.md`](../docs/publication.md).
Nothing is committed under this course.

No graded work, notes, or syllabus for this course exists in either source. The course
was absent from the repository entirely until the author's audit surfaced it.
